# Posture Analysis

ระบบทำรายงาน Posture Analysis สำหรับนักกายภาพบำบัด
- เป็นเว็บแอปที่ **ใช้งานแบบออฟไลน์ได้** และติดตั้งเป็นโปรแกรมบนคอมพิวเตอร์ได้
- **เก็บไฟล์เคสในโฟลเดอร์ที่เลือกเองในเครื่อง**
- ข้อมูลผู้รับบริการไม่ถูกส่งออกไปที่ใด

## เริ่มใช้งาน

1. เปิด https://yahkuza99.github.io/posture-analysis/ ด้วย **Google Chrome** หรือ **Microsoft Edge** บนคอมพิวเตอร์
2. **ติดตั้งเป็นแอป (แนะนำ):** กดปุ่ม **"ติดตั้งแอป"** มุมขวาบน หรือไอคอนติดตั้งในช่อง URL
   - จะได้ไอคอนบนเดสก์ท็อปและเมนู Start เปิดเป็นหน้าต่างของตัวเอง
3. **ตั้งที่เก็บไฟล์:** กดปุ่ม **"📁 ยังไม่ได้ตั้งที่เก็บไฟล์"** แล้วเลือกโฟลเดอร์ เช่น `Documents/Posture Cases`
4. **ตั้งค่า:** ใส่โลโก้คลินิก, ภาพ Muscle chart และชื่อนักกายภาพเริ่มต้น ที่ปุ่ม **ตั้งค่า**

### ใช้งานแบบออฟไลน์
- เปิดผ่านเว็บครั้งแรกตอนมีอินเทอร์เน็ต ระบบจะเก็บตัวโปรแกรมไว้ในเครื่อง
- หลังจากนั้นเปิดได้แม้ไม่มีอินเทอร์เน็ต (ในหน้าตั้งค่าจะขึ้นว่า "พร้อมใช้งานออฟไลน์ ✓")
- เมื่อมีเวอร์ชันใหม่และเครื่องต่ออินเทอร์เน็ต มุมขวาล่างจะขึ้น **"มีเวอร์ชันใหม่ — อัปเดตเลย"**
  - ระบบบันทึกเคสที่เปิดอยู่ให้ก่อนอัปเดต

### ที่เก็บไฟล์เคส
- กด **บันทึก** (Ctrl+S) ครั้งแรก เคสจะถูกเขียนลงโฟลเดอร์ที่ตั้งไว้ ชื่อไฟล์เป็น `CN_ชื่อ_นามสกุล_วันที่.json`
- **หลังบันทึกครั้งแรก ทุกการแก้ไขจะบันทึกลงไฟล์เดิมอัตโนมัติ**
  - ถ้าแก้ CN, ชื่อ หรือวันที่ แล้วกดบันทึก ชื่อไฟล์จะเปลี่ยนตาม
- **เปิดเคส** (Ctrl+O): แสดงรายการเคสในโฟลเดอร์ เรียงจากล่าสุด ค้นหาด้วย CN หรือชื่อได้
- ไฟล์เคสมีรูปถ่ายอยู่ในไฟล์ด้วย ย้ายเครื่องได้ด้วยการก็อปโฟลเดอร์ไปทั้งโฟลเดอร์
- เบราว์เซอร์จะขออนุญาตเข้าโฟลเดอร์ทุกครั้งที่เปิดโปรแกรมใหม่ ให้กดปุ่มโฟลเดอร์สีเหลือง แล้วเลือก "อนุญาต"
- Firefox และ Safari เลือกโฟลเดอร์ไม่ได้ ระบบจะดาวน์โหลดไฟล์ไปที่ Downloads แทน

### สำรองข้อมูล (แนะนำหลัก 3-2-1)

| ชุด | เก็บที่ | ทำงานอย่างไร |
|---|---|---|
| ตัวจริง | โฟลเดอร์เคสใน **OneDrive หรือ Google Drive for Desktop** (บัญชีคลินิก เปิด 2FA) | ซิงก์ขึ้นคลาวด์และเก็บประวัติเวอร์ชันย้อนหลังให้เอง |
| สำรองทันที | **ฮาร์ดดิสก์ภายนอกหรือ NAS** ตั้งเป็น "โฟลเดอร์สำรอง" ในหน้าตั้งค่า | ทุกครั้งที่บันทึก โปรแกรมคัดลอกเคสไปที่ `โฟลเดอร์สำรอง/cases/` |
| สำรองรายสัปดาห์ | กด **"สำรองทั้งหมดตอนนี้"** | สร้างไฟล์ `posture-backup_วันที่_เวลา.zip` ในโฟลเดอร์สำรอง เก็บไว้ 12 ไฟล์ล่าสุด |

- **ไฟล์ ZIP:** มีทุกเคส (พร้อมรูป) และการตั้งค่าคลินิก (โลโก้ ภาพ Muscle chart ชื่อนักกายภาพ)
- **แจ้งเตือน:** ถ้าไม่ได้สำรองทั้งหมดเกิน 7 วัน แถบบนจะขึ้นปุ่มเตือนสีเหลือง กดแล้วสำรองทันที
- **กู้คืน:** ตั้งค่า → **กู้คืนจากไฟล์สำรอง** แล้วเลือกไฟล์ ZIP
  - เลือกได้ว่าจะเขียนทับเคสที่มีอยู่ หรือกู้เฉพาะเคสที่หายไป
  - เปิดไฟล์ ZIP ด้วยโปรแกรมทั่วไปได้ ไฟล์เคสข้างในเป็น `.json`

### ความเป็นส่วนตัว
- ไฟล์เคสเป็นข้อมูลสุขภาพ (ข้อมูลอ่อนไหวตาม PDPA) ควรเก็บในเครื่องหรือไดรฟ์ที่มีรหัสผ่าน และจำกัดผู้เข้าถึง
  - ฮาร์ดดิสก์สำรองควรเข้ารหัสด้วย (BitLocker / FileVault)
- **ไม่มีการส่งข้อมูลออกนอกเครื่อง:** ทุกไฟล์ของโปรแกรม รวมถึงฟอนต์ อยู่ในตัวแอปเอง
  ระบบทดสอบอัตโนมัติตรวจข้อนี้ทุกครั้งที่อัปเดต

## ขั้นตอนทำรายงาน

1. กรอก Name / Lastname / CN / Physical Therapist / DATE
   ข้อมูลจะไปแสดงทุกหน้าเอง
2. **หน้า 1 Posture Chart:** คลิกกรอบรูปเพื่อเลือกรูป หรือลากไฟล์มาวาง
   - ลากรูปในกรอบเพื่อจัดตำแหน่ง ใช้ปุ่ม ＋/－ เพื่อซูม และปุ่ม ⟲ เพื่อจัดกึ่งกลาง
   - พอวางเส้นดิ่ง (G) แล้ว รูปจะเลื่อนให้เส้นดิ่งอยู่กึ่งกลางกรอบเอง ถ้าลากรูปไปแล้ว กดปุ่ม ⟲ เพื่อกลับมากึ่งกลาง
   - **เส้นกึ่งกลางกรอบ (สีชมพู):** ขึ้นตอนเอาเมาส์ชี้หรือลากรูป ถ้าลากเข้าใกล้กึ่งกลาง รูปจะดูดเข้าตรงกลางเองพร้อมป้าย "เส้นดิ่งอยู่กึ่งกลาง ✓" หรือ "กึ่งกลางรูป ✓" เส้นนี้ไม่ออกตอนพิมพ์
   - กด **วางจุด/เส้น** (หรือดับเบิลคลิกที่รูป) เพื่อเปิดหน้าจอวาง landmark
3. **ผลตรวจ (กล่องตรงกลาง):** เลือกจาก "ข้อความสำเร็จรูป" หรือกด "+ กล่องว่าง" แล้วพิมพ์เอง
   - ตัวเลือก Q-angle จะดึงค่าที่วัดจากรูปด้านหน้ามาใส่ให้อัตโนมัติ
4. **หน้า 2 Functional Analysis:** ใส่รูป Single leg stance และ Squat แล้วพิมพ์ผลการตรวจ
5. **หน้า 3 Muscle Chart:** เลือก "ตึงตัว" (ฟ้า) หรือ "อ่อนแรง" (เหลือง) แล้ววาดบนภาพกล้ามเนื้อ
   - กดค้างแล้วลากตามแนวกล้ามเนื้อ จะได้วงรีเรียบร้อยตามทิศที่ลาก ปรับความกว้างด้วย "ความกว้างวงรี"
   - คลิกครั้งเดียวจะได้วงกลมเล็ก ใช้ "ยางลบ" คลิกที่วงรีเพื่อลบ
   - กรอกรายชื่อกล้ามเนื้อ, Impression, Recommendation และ Rechecked by
   - ช่อง Impression / Recommendation มีขนาดคงที่ ถ้าข้อความยาว ตัวหนังสือจะเล็กลงเอง ภาพไม่ถูกย่อ
     ถ้ากรอบเป็นสีแดง แปลว่ายาวเกินแม้ใช้ตัวเล็กสุดแล้ว ควรตัดข้อความให้สั้นลง
6. กด **พิมพ์ / PDF** แล้วตั้งค่าดังนี้
   - ปลายทาง: "บันทึกเป็น PDF"
   - ขนาดกระดาษ: A4
   - ขอบกระดาษ: ไม่มี (None)
   - เปิด "กราฟิกพื้นหลัง" (Background graphics)

## วางจุด Landmark ตามโปรโตคอล

เปิดรูปด้วย **วางจุด/เส้น** (หรือดับเบิลคลิกที่รูป) ระบบจะเริ่มวางจุดตามลำดับให้เอง
แถบซ้ายบอกจุดที่ต้องคลิกต่อไป พร้อมคำอธิบายตำแหน่งทางกายวิภาค

| มุมมอง | จุด landmark |
|---|---|
| ด้านหน้า | ตา R/L, Acromion R/L, ASIS R/L, กึ่งกลางลูกสะบ้า R/L, Tibial tuberosity R/L, กึ่งกลางข้อเท้า R/L |
| ด้านหลัง | ท้ายทอย, C7, Acromion R/L, มุมล่างสะบัก R/L, PSIS R/L, กึ่งกลางส้นเท้า R/L |
| ด้านข้าง | Tragus, C7, Acromion, Greater trochanter, แนวข้อเข่าด้านนอก, ตาตุ่มนอก |
| ยืนขาเดียว | C7, PSIS R/L, ส้นเท้าขาที่ยืน |
| Squat ด้านหลัง | PSIS R/L, กึ่งกลางเข่า R/L, กึ่งกลางข้อเท้า R/L |
| Squat ด้านข้าง | Acromion, Greater trochanter, แนวข้อเข่าด้านนอก, ตาตุ่มนอก |

### วิธีวางจุด
- **วางจุด:** คลิกจุดตามลำดับ ระบบเลื่อนไปจุดถัดไปเอง
- **ข้ามจุด:** กด **Tab** หรือปุ่ม "ข้าม"
- **ย้ายจุด:** ลากจุดที่วางแล้ว หรือคลิกชื่อจุดในรายการแล้วคลิกตำแหน่งใหม่
- **ขยับละเอียด:** คลิกจุดเพื่อเลือก (มีกรอบสีชมพู) แล้วกดลูกศร ←↑→↓ ขยับทีละ 1 พิกเซล (Shift = ทีละ 10) จุดที่เพิ่งวางถูกเลือกไว้ให้แล้ว
- **แว่นขยาย 3 เท่า:** แสดงข้างเคอร์เซอร์ขณะวางจุด ช่วยให้วางได้แม่นยำ
- **ชื่อจุด:** แสดงใต้แต่ละจุดบนหน้าจอ (ปิดได้) แต่ไม่พิมพ์ลงรายงาน

### ผลวิเคราะห์อัตโนมัติ (แถบขวา)

ระบบลากเส้นอ้างอิงจากจุดที่วางให้เอง และแปลผลเป็นข้อความโดยระบุข้างของผู้รับบริการ
(รูปด้านหน้ากลับซ้าย-ขวาให้อัตโนมัติ)

- **เส้นดิ่ง:** ผ่านกึ่งกลางข้อเท้าหรือส้นเท้า ส่วนรูปด้านข้างผ่านตาตุ่มนอก
- **ด้านหน้าและด้านหลัง:**
  - ระดับตา ไหล่ มุมล่างสะบัก และเชิงกราน (องศา)
  - Q-angle ทั้งสองข้าง
  - ลำตัวเยื้องจากแนวดิ่ง และลำตัวเอียง
  - สะบักห่างจากแนวกระดูกสันหลังไม่เท่ากัน
- **ด้านข้าง:**
  - CVA (Craniovertebral angle) ถ้าต่ำกว่า 50° ระบบบอกว่าศีรษะยื่นไปด้านหน้า
  - ติ่งหู ไหล่ สะโพก เข่า อยู่หน้าหรือหลังแนวดิ่ง (เส้นสีเขียว = ปกติ สีส้ม = เยื้อง)
- **Functional:**
  - เชิงกรานตกขณะยืนขาเดียว (Trendelenburg)
  - เข่าเคลื่อนเข้าด้านในขณะ Squat
  - มุมลำตัวเทียบกับมุมหน้าแข้ง

ข้อที่ผิดปกติถูกติ๊กไว้ให้ก่อน กด **"ใส่ที่เลือกลงผลตรวจ"** เพื่อส่งลงรายงาน

เกณฑ์ตัดสินอยู่ที่ `THRESHOLDS` ใน `js/protocol.js` ปรับได้ตามแนวทางของคลินิก
ผลวิเคราะห์เป็นข้อมูลประกอบ ผู้ประเมินควรตรวจทานทุกข้อ

### ตั้งสเกลเป็นเซนติเมตร
1. เปิด "เครื่องมืออิสระ" แล้วเลือก **ตั้งสเกล (K)**
2. คลิกสองปลายของสิ่งที่รู้ความยาวจริง เช่น ช่องกริดบนฉากหลัง หรือไม้วัด
3. ใส่ความยาวจริงเป็นเซนติเมตร

หลังตั้งสเกล ระยะการเยื้องในผลวิเคราะห์จะแสดงเป็นเซนติเมตร

### เครื่องมืออิสระ

| ปุ่ม | คีย์ลัด | ใช้ทำอะไร |
|---|---|---|
| วางจุดตามลำดับ | M | กลับไปวางจุดตามโปรโตคอล |
| เลือก/ย้าย | V | เลือกเส้น ลากจุดเพื่อปรับตำแหน่ง ลากตัวเส้นเพื่อย้าย |
| จุด | P | วางจุดเพิ่มเติม |
| เส้นดิ่ง | G | เส้นแนวตั้ง (plumb line) คลิกจุดเดียว |
| เส้นระดับ | L | คลิก 2 จุด แสดงมุมเอียงให้ |
| เส้นตรง | D | เส้นทึบเชื่อม 2 จุด |
| มุม | A | วัดมุม 3 จุด (ปลาย – จุดยอด – ปลาย) |
| Q-angle | Q | คลิก ASIS → Patella → Tibial tuberosity |
| ข้อความ | T | วางข้อความบนรูป |
| ตั้งสเกล | K | กำหนดระยะจริงเป็นเซนติเมตร |

**คีย์ลัด:**
- **Ctrl+Z** ย้อนกลับ
- **Delete** ลบเส้นหรือจุดที่เลือก
- **Esc** ปิดหน้าต่าง
