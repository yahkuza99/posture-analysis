# Posture Analysis

ระบบทำรายงาน Posture Analysis สำหรับนักกายภาพบำบัด
- เป็นเว็บแอปที่ **ใช้งานแบบออฟไลน์ได้** และติดตั้งเป็นโปรแกรมบนคอมพิวเตอร์ได้
- **เก็บไฟล์เคสในโฟลเดอร์ที่เลือกเองในเครื่อง**
- ข้อมูลผู้รับบริการไม่ถูกส่งออกไปที่ใด

## เริ่มใช้งาน

1. เปิด https://yahkuza99.github.io/posture-analysis/ ด้วย **Google Chrome** หรือ **Microsoft Edge** บนคอมพิวเตอร์
2. **ติดตั้งเป็นแอป (แนะนำ):** กดปุ่ม **"ติดตั้งแอป"** มุมขวาบน หรือไอคอนติดตั้งในช่อง URL
   - จะได้ไอคอนบนเดสก์ท็อปและเมนู Start เปิดเป็นหน้าต่างของตัวเอง
3. **ตั้งที่เก็บไฟล์:** กดปุ่ม **"📁 ยังไม่ได้ตั้งที่เก็บไฟล์"** แล้วเลือกโฟลเดอร์ เช่น `Documents/Posture Cases`
4. **ตั้งค่า:** ใส่โลโก้คลินิก, ภาพ Muscle chart และชื่อนักกายภาพเริ่มต้น ที่ปุ่ม **ตั้งค่า**

### ใช้งานแบบออฟไลน์
- เปิดผ่านเว็บครั้งแรกตอนมีอินเทอร์เน็ต ระบบจะเก็บตัวโปรแกรมไว้ในเครื่อง
- หลังจากนั้นเปิดได้แม้ไม่มีอินเทอร์เน็ต (ในหน้าตั้งค่าจะขึ้นว่า "พร้อมใช้งานออฟไลน์ ✓")
- เมื่อมีเวอร์ชันใหม่และเครื่องต่ออินเทอร์เน็ต มุมขวาล่างจะขึ้น **"มีเวอร์ชันใหม่ — อัปเดตเลย"**
  - ระบบบันทึกเคสที่เปิดอยู่ให้ก่อนอัปเดต

### ที่เก็บไฟล์เคส
- กด **บันทึก** (Ctrl+S) ครั้งแรก เคสจะถูกเขียนลงโฟลเดอร์ที่ตั้งไว้ ชื่อไฟล์เป็น `CN_ชื่อ_นามสกุล_วันที่.json`
- **หลังบันทึกครั้งแรก ทุกการแก้ไขจะบันทึกลงไฟล์เดิมอัตโนมัติ**
  - ถ้าแก้ CN, ชื่อ หรือวันที่ แล้วกดบันทึก ชื่อไฟล์จะเปลี่ยนตาม
- **เปิดเคส** (Ctrl+O): แสดงรายการเคสในโฟลเดอร์ เรียงจากล่าสุด ค้นหาด้วย CN หรือชื่อได้
- ไฟล์เคสมีรูปถ่ายอยู่ในไฟล์ด้วย ย้ายเครื่องได้ด้วยการก็อปโฟลเดอร์ไปทั้งโฟลเดอร์
- เบราว์เซอร์จะขออนุญาตเข้าโฟลเดอร์ทุกครั้งที่เปิดโปรแกรมใหม่ ให้กดปุ่มโฟลเดอร์สีเหลือง แล้วเลือก "อนุญาต"
- Firefox และ Safari เลือกโฟลเดอร์ไม่ได้ ระบบจะดาวน์โหลดไฟล์ไปที่ Downloads แทน

### สำรองข้อมูลและความเป็นส่วนตัว
- **สำรองข้อมูล:** ตั้งโฟลเดอร์เคสไว้ใน OneDrive, Google Drive for Desktop หรือ NAS ของคลินิก
  ไฟล์จะถูกสำรองโดยอัตโนมัติ
- ไฟล์เคสเป็นข้อมูลสุขภาพ (ข้อมูลอ่อนไหวตาม PDPA) ควรเก็บในเครื่องหรือไดรฟ์ที่มีรหัสผ่าน
  และจำกัดผู้เข้าถึง
- **ไม่มีการส่งข้อมูลออกนอกเครื่อง:** ทุกไฟล์ของโปรแกรม รวมถึงฟอนต์ อยู่ในตัวแอปเอง
  ระบบทดสอบอัตโนมัติตรวจข้อนี้ทุกครั้งที่อัปเดต

## License และการขาย

ระบบ license ทำงานแบบออฟไลน์ทั้งหมด ไม่ต้องมีเซิร์ฟเวอร์

- **ตรวจ license:** ผู้ขายลงลายเซ็นดิจิทัล (ECDSA P-256) ด้วย "กุญแจลับ" ส่วนโปรแกรมตรวจด้วย "กุญแจสาธารณะ" ที่ฝังไว้ จึงปลอมหรือแก้ชื่อใน license ไม่ได้
- **ไม่มี license หรือหมดอายุ:** ใช้งานได้ครบ แต่รายงานที่พิมพ์มีลายน้ำ "ฉบับทดลอง · TRIAL"
- **มี license:** ไม่มีลายน้ำ และท้ายรายงานทุกหน้าพิมพ์ "ใช้งานภายใต้ license: <ชื่อคลินิก>"
- **ข้อจำกัด:** เป็นระบบกันคนทั่วไปใช้โดยไม่ได้ซื้อ คนที่ตั้งใจแก้โค้ดในเบราว์เซอร์ยังข้ามได้

### ตั้งค่าครั้งแรก (ผู้ขาย)
1. เปิด `tools/license-admin.html` (บนเว็บที่ `/tools/license-admin.html` หรือจากไฟล์) ด้วย Chrome หรือ Edge
2. กด **สร้างกุญแจใหม่** จะได้ไฟล์ `posture-license-PRIVATE-KEY.json`
   - **เก็บไฟล์นี้เป็นความลับและสำรองไว้**
3. คัดลอก "กุญแจสาธารณะ" ไปใส่ที่ `LICENSE_PUBLIC_KEY` ใน `js/app.js` แล้ว push
   - ก่อนใส่กุญแจนี้ ทุกเครื่องจะเป็นโหมดทดลอง

### ออก license ให้ลูกค้า
1. เปิดเครื่องมือออก license แล้วเปิดไฟล์กุญแจลับ
2. กรอกชื่อคลินิกและอายุ (1 เดือน / 6 เดือน / 1 ปี / ไม่มีวันหมดอายุ / กำหนดเอง)
3. ส่ง license key หรือไฟล์ `.license` ให้ลูกค้า
4. ลูกค้ากด **"ทดลองใช้ — ใส่ license"** แล้ววาง key หรือเปิดไฟล์
5. รายการ license ที่ออกแล้วดาวน์โหลดเป็น CSV เก็บเป็นทะเบียนได้

### ส่งโปรแกรมให้ลูกค้า
- **แบบเว็บ (อัปเดตอัตโนมัติ):** ส่งลิงก์เว็บ ลูกค้ากด "ติดตั้งแอป"
- **แบบไฟล์ (ไม่ต้องใช้อินเทอร์เน็ตเลย):** ส่ง `posture-analysis.zip` จาก `/download/posture-analysis.zip` บนเว็บ
  - สร้างใหม่อัตโนมัติทุกครั้งที่ deploy
  - ในไฟล์มี `README.txt` วิธีติดตั้งภาษาไทย และไม่มีเครื่องมือออก license ติดไปด้วย
- ข้อตกลงการใช้งานและความเป็นส่วนตัว: `terms.html` (เปิดได้จากหน้าตั้งค่า)
  - **ควรให้นักกฎหมายตรวจก่อนใช้จริง**

## ขั้นตอนทำรายงาน

1. กรอก Name / Lastname / CN / Physical Therapist / DATE
   ข้อมูลจะไปแสดงทุกหน้าเอง
2. **หน้า 1 Posture Chart:** คลิกกรอบรูปเพื่อเลือกรูป หรือลากไฟล์มาวาง
   - ลากรูปในกรอบเพื่อจัดตำแหน่ง ใช้ปุ่ม ＋/－ เพื่อซูม และปุ่ม ⟲ เพื่อจัดกึ่งกลาง
   - พอวางเส้นดิ่ง (G) แล้ว รูปจะเลื่อนให้เส้นดิ่งอยู่กึ่งกลางกรอบเอง ถ้าลากรูปไปแล้ว กดปุ่ม ⟲ เพื่อกลับมากึ่งกลาง
   - กด **วางจุด/เส้น** (หรือดับเบิลคลิกที่รูป) เพื่อเปิดหน้าจอวาง landmark
3. **ผลตรวจ (กล่องตรงกลาง):** เลือกจาก "ข้อความสำเร็จรูป" หรือกด "+ กล่องว่าง" แล้วพิมพ์เอง
   - ตัวเลือก Q-angle จะดึงค่าที่วัดจากรูปด้านหน้ามาใส่ให้อัตโนมัติ
4. **หน้า 2 Functional Analysis:** ใส่รูป Single leg stance และ Squat แล้วพิมพ์ผลการตรวจ
5. **หน้า 3 Muscle Chart:** เลือก "ตึงตัว" (ฟ้า) หรือ "อ่อนแรง" (เหลือง) แล้ววาดบนภาพกล้ามเนื้อ
   - กดค้างแล้วลากตามแนวกล้ามเนื้อ จะได้วงรีเรียบร้อยตามทิศที่ลาก ปรับความกว้างด้วย "ความกว้างวงรี"
   - คลิกครั้งเดียวจะได้วงกลมเล็ก ใช้ "ยางลบ" คลิกที่วงรีเพื่อลบ
   - กรอกรายชื่อกล้ามเนื้อ, Impression, Recommendation และ Rechecked by
   - ช่อง Impression / Recommendation มีขนาดคงที่ ถ้าข้อความยาว ตัวหนังสือจะเล็กลงเอง ภาพไม่ถูกย่อ
     ถ้ากรอบเป็นสีแดง แปลว่ายาวเกินแม้ใช้ตัวเล็กสุดแล้ว ควรตัดข้อความให้สั้นลง
6. กด **พิมพ์ / PDF** แล้วตั้งค่าดังนี้
   - ปลายทาง: "บันทึกเป็น PDF"
   - ขนาดกระดาษ: A4
   - ขอบกระดาษ: ไม่มี (None)
   - เปิด "กราฟิกพื้นหลัง" (Background graphics)

## เครื่องมือวางจุด/เส้น

| ปุ่ม | คีย์ลัด | ใช้ทำอะไร |
|---|---|---|
| เลือก/ย้าย | V | เลือกเส้น ลากจุดเพื่อปรับตำแหน่ง ลากตัวเส้นเพื่อย้าย |
| จุด | P | วางจุด landmark |
| เส้นดิ่ง | G | เส้นแนวตั้ง (plumb line) คลิกจุดเดียว |
| เส้นระดับ | L | คลิก 2 จุด เช่น ไหล่ซ้าย-ขวา แสดงมุมเอียงให้ |
| เส้นตรง | D | เส้นทึบเชื่อม 2 จุด เช่น แนวขา |
| มุม | A | วัดมุม 3 จุด (ปลาย – จุดยอด – ปลาย) |
| Q-angle | Q | คลิก ASIS → Patella → Tibial tuberosity |
| ข้อความ | T | วางข้อความบนรูป |

อื่น ๆ:
- **Ctrl+Z** ย้อนกลับ, **Delete** ลบเส้นที่เลือก, **Esc** ยกเลิกเส้นที่วาดค้างอยู่
- หมุนลูกกลิ้งเพื่อซูม กดค้างแล้วลากบนภาพเพื่อเลื่อนภาพ (คลิกเฉย ๆ = วางจุด)
- **ค่าที่วัดได้** ในแถบซ้ายบอกว่าข้างไหนสูงกว่า โดยคิดตามด้านของผู้รับบริการแล้ว
  (รูปด้านหน้ากลับซ้าย-ขวาให้อัตโนมัติ) กด "+ ใส่ในผลตรวจ" เพื่อเพิ่มลงรายงานได้เลย

## ปรับแต่ง

- ข้อความสำเร็จรูป: แก้ `PRESETS` ใน `js/app.js`
- **โลโก้คลินิก:** กด "+ ใส่โลโก้คลินิก" ที่หัวกระดาษ หรือที่ **ตั้งค่า**
- **ภาพกล้ามเนื้อ (Muscle chart):** คลิกกรอบในหน้า 3 หรือกด "เปลี่ยนภาพ"

ทั้งสองอย่างใส่ครั้งเดียว ระบบจะจำไว้ในเบราว์เซอร์ของเครื่องนั้นและใช้กับทุกเคส
ไม่ได้อัปโหลดขึ้น GitHub ถ้าใช้หลายเครื่องต้องใส่ในแต่ละเครื่อง

## สำหรับนักพัฒนา

```
index.html              หน้ารายงาน 3 หน้า (A4) และหน้าต่างตั้งค่า/เปิดเคส
css/style.css           หน้าตาและรูปแบบการพิมพ์
css/fonts.css, fonts/   ฟอนต์ Sarabun และ Montserrat (SIL OFL 1.1 ใช้เชิงพาณิชย์ได้ — fonts/OFL.txt)
js/app.js               การทำงานทั้งหมด
sw.js                   service worker สำหรับใช้งานออฟไลน์
manifest.webmanifest    ข้อมูลสำหรับติดตั้งเป็นแอป
icons/                  ไอคอนแอป
tests/                  ทดสอบอัตโนมัติ (Playwright) และเซิร์ฟเวอร์สำหรับรันในเครื่อง
tools/license-admin.html เครื่องมือออก license (สำหรับผู้ขาย)
terms.html              ข้อตกลงการใช้งานและความเป็นส่วนตัว
dist-files/README.txt   คู่มือที่แนบไปในไฟล์ ZIP สำหรับลูกค้า
```

- รันในเครื่อง: `npm run serve` แล้วเปิด http://localhost:8080
- ทดสอบ: `npm install && npx playwright install chromium && npm test`
- **Deploy:** push ขึ้น `main` แล้ว GitHub Actions จะทำตามลำดับนี้
  1. รันทดสอบก่อน
  2. ถ้าผ่าน จะประทับเลขเวอร์ชัน (commit) ลงไฟล์ แล้ว deploy ขึ้น GitHub Pages
  3. ถ้าทดสอบไม่ผ่าน จะไม่ deploy เว็บที่ใช้งานอยู่จึงไม่พัง
