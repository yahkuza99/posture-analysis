Posture Analysis — วิธีติดตั้งและใช้งาน
=========================================

ใช้กับ Google Chrome หรือ Microsoft Edge บนคอมพิวเตอร์ (Windows / Mac)

วิธีที่ 1: ใช้จากไฟล์ (ไม่ต้องต่ออินเทอร์เน็ตเลย)
  1. แตกไฟล์ ZIP ไปไว้ในโฟลเดอร์ที่ต้องการ เช่น Documents\Posture Analysis
     (ต้องแตกไฟล์ก่อน ห้ามเปิดจากในไฟล์ ZIP ตรง ๆ)
  2. คลิกขวาที่ index.html → Open with → Google Chrome หรือ Microsoft Edge
  3. ทำ bookmark หน้านี้ไว้ จะได้เปิดครั้งต่อไปได้ง่าย

วิธีที่ 2: ติดตั้งเป็นแอปจากเว็บ (อัปเดตอัตโนมัติ)
  1. เปิดลิงก์เว็บที่ได้รับจากผู้จำหน่าย แล้วกดปุ่ม "ติดตั้งแอป" มุมขวาบน
  2. หลังเปิดครั้งแรกแล้ว ใช้งานแบบไม่ต่ออินเทอร์เน็ตได้

ตั้งค่าครั้งแรก
  1. กดปุ่ม 📁 มุมขวาบน แล้วเลือกโฟลเดอร์เก็บไฟล์เคส เช่น Documents\Posture Cases
  2. กด "ตั้งค่า" แล้วใส่โลโก้คลินิก, ภาพ Muscle chart และชื่อนักกายภาพ
  3. กด "ทดลองใช้ — ใส่ license" แล้ววาง license key ที่ได้รับ หรือเปิดไฟล์ .license
     (ถ้ายังไม่ใส่ license รายงานที่พิมพ์จะมีลายน้ำ "ฉบับทดลอง")

สำรองข้อมูล
  ไฟล์เคสทุกไฟล์อยู่ในโฟลเดอร์ที่เลือกในข้อ 1 ควรตั้งโฟลเดอร์นี้ไว้ใน OneDrive / Google Drive
  หรือก็อปสำรองเป็นประจำ ไฟล์เคสมีข้อมูลสุขภาพของผู้รับบริการ ควรเก็บในเครื่องที่มีรหัสผ่าน
